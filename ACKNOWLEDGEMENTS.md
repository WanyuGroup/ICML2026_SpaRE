# Acknowledgements

SpaRE represents molecules with Group SELFIES-style bracket tokens. We
acknowledge the Group SELFIES project by the Aspuru-Guzik group:

- Repository: https://github.com/aspuru-guzik-group/group-selfies
- License: Apache License 2.0
- Paper: "Group SELFIES: A Robust Fragment-Based Molecular String
  Representation"

Group SELFIES extends SELFIES with group tokens that can represent functional
groups or larger molecular substructures. This repository does not vendor the
Group SELFIES source code; users who install or use that package should follow
the upstream license and citation requirements.
