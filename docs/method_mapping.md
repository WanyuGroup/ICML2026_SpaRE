## Foundation Model Fine-Tuning

Paper:

- Base model: MolXPT-style GPT-2 molecular LM.
- Data: text-to-molecule records, with natural-language `text` prompts and
  Group SELFIES-formatted molecule targets.
- Tokenization: all Group SELFIES bracket tokens found in the fine-tuning
  targets are added to the tokenizer before the model embedding matrix is
  resized.
- Objective: standard autoregressive next-token loss.
- Main hyperparameters: 2 epochs, AdamW, learning rate `5e-5`, no weight decay,
  max sequence length `1024`, batch size `64`.

Code:

- `spare finetune`
- `spare_molgen.finetune.finetune_causal_lm`

The implementation is model-agnostic and accepts a Hugging Face model path or
model id. Fine-tuned checkpoints are generated by running `spare finetune`.

## SAE Training

Paper:

- Train independent SAEs on activations from each transformer layer.
- Input dimension: `1024` in the reported model.
- Expansion factor: `40x`.
- Loss: MSE reconstruction plus L1 sparsity penalty.
- Reported SAE training: 8 epochs, batch size `1024`, learning rate `1e-4`.

Code:

- `spare collect-activations`
- `spare train-sae`
- `spare_molgen.sae.SparseAutoencoder`
- `spare_molgen.activation_store`

The code stores activation shards locally and trains SAEs from those shards.
The default optimizer is AdamW for portability. A local Muon optimizer can be
selected when available with `--optimizer muon`.

## Local Control

Paper:

- Use a late layer, empirically layer `22`, for token-level local control.
- Identify features whose SAE activations exceed threshold `0.5` in all samples
  for the target atom or functional group.
- Average the selected SAE decoder dictionary vectors.
- Inject the concept vector only at the target generation step.

Code:

- `spare extract-local`
- `spare generate --local-step N`
- `spare_molgen.concepts.build_local_concept`
- `spare_molgen.hooks.ActivationEditor`

`spare extract-local --token TOKEN --tokenizer MODEL_OR_TOKENIZER_DIR` supports
any token already present in the tokenizer. Missing tokens raise an error.

## Global Control

Paper:

- Use an earlier layer, empirically layer `10`, for global property control.
- Build positive and negative exemplar sets.
- Contrast their sparse activation patterns.
- Decode a property direction and inject it at every generation step.

Code:

- `spare extract-global`
- `spare generate`
- `spare_molgen.concepts.build_global_concept`
- `spare_molgen.generation.generate_with_edits`
