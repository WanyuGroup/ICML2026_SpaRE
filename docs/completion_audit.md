# Completion Audit

Objective: publish only the six basic SpaRE workflow scripts: fine-tuning,
activation collection, SAE training, local control-vector extraction, global
control-vector extraction, and controlled generation. No additional method
surface, including MCTS, is included.

## Prompt-To-Artifact Checklist

| Requirement | Evidence |
| --- | --- |
| Tie the repository to the paper | `README.md`, `CITATION.bib`, and `CITATION.cff` include the ICML 2026/OpenReview citation. |
| Acknowledge Group SELFIES | `NOTICE`, `ACKNOWLEDGEMENTS.md`, and `docs/third_party.md` record the upstream repository, Apache-2.0 license, and citation. |
| Read the paper and implement from the described method | `docs/method_mapping.md` maps the paper sections to source modules. |
| Open-source only six basic scripts | `scripts/` contains exactly `finetune.sh`, `collect_activations.sh`, `train_sae.sh`, `extract_local_vector.sh`, `extract_global_vector.sh`, and `controlled_generate.sh`. |
| Public CLI is limited to six commands | `tests/test_cli_surface.py` verifies the public `spare` command choices. |
| Training checkpoints are generated by scripts | `README.md`, `scripts/finetune.sh`, and `scripts/train_sae.sh` document the local checkpoint path. |
| Prompt is natural-language text | `README.md`, `docs/reproducibility.md`, and `examples/toy_molecules.jsonl` use `text` as prompt and `group_selfies` as target. |
| Open the whole training process | `spare finetune`, `spare collect-activations`, and `spare train-sae` implement the training path. |
| Open the inference process | `spare extract-local`, `spare extract-global`, and `spare generate` implement concept extraction and activation-edited generation. |
| Support local and global SpaRE control | `src/spare_molgen/concepts.py`, `src/spare_molgen/hooks.py`, and `src/spare_molgen/generation.py`. |
| Exclude MCTS and extra scoring code | `src/spare_molgen/mcts.py`, `src/spare_molgen/chem.py`, and the `chem` optional dependency are absent. |
| Avoid publishing the review PDF | The release repository is `spare-molgen/`; the original PDF remains outside it in the parent working directory. |
| Provide reproducible command examples | `README.md` and `configs/*.yaml`. |
| Provide reviewer-facing artifact instructions | `docs/artifact_evaluation.md` documents quick checks that do not require private artifacts. |
| Provide a CI gate for publication | `.github/workflows/ci.yml` installs the package, runs compile checks, internal release checks, and tests. |
